# Release Checklist

Before publishing a release, verify:

- The repository still contains the six skills only.
- Each skill has seven English canonical files.
- Each skill has a complete `zh-CN/` mirror.
- `README.md` is the English canonical entry.
- `README.zh-CN.md` exists.
- `examples/nova_compute_end_to_end.md` is English.
- `examples/nova_compute_end_to_end.zh-CN.md` exists.
- All examples use fictional NovaCompute materials.
- All example numbers, customers, revenue, financing, valuation, and transaction terms are marked as fictional examples.
- No API keys, tokens, local absolute paths, or private project materials are present.
- No real project names or real customer names are present.
- No investment recommendation, legal, financial, tax, or securities trading advice is present.
- Markdown relative links are valid.
- Mermaid workflow renders.
- The release notes clearly state the public boundary.

# Contributing

Thank you for considering a contribution to AI Investment Workflow Skills.

## Scope

This repository is focused on investor-style company research workflows. Contributions should preserve the primary-market diligence lens and evidence discipline.

## Before Adding or Editing a Skill

- Keep the six-skill workflow coherent.
- Do not add a new skill unless the repository scope is explicitly expanded in a future release.
- Keep examples fictional.
- Do not include real customer names, financing details, revenue data, valuation data, transaction terms, or private materials.
- Do not create wording that sounds like investment advice, legal advice, tax advice, financial advice, or securities trading advice.

## Skill File Expectations

Each skill should keep these files:

- `README.md`
- `skill.md`
- `input_contract.md`
- `output_schema.md`
- `example_input.md`
- `example_output.md`
- `quality_checklist.md`

If the English canonical file changes, update the `zh-CN/` mirror or clearly mark that a mirror update is pending.

## Evidence Discipline

Use the shared evidence labels:

`user_provided`, `company_claim`, `interview_note`, `financial_snapshot`, `third_party_unverified`, `inferred`, `missing_evidence`, `needs_human_review`.

## Pull Request Checklist

- The contribution keeps the investment research lens.
- Examples are fictional.
- Evidence labels are present where needed.
- Prohibited conclusions are not used.
- Markdown links are valid.
- The Chinese mirror is updated when relevant.
